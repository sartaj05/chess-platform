Offline LAN Multiplayer

This platform can run inside a private network without internet. Start Docker on the host machine, create a LAN room, and share the local URL with another computer on the same network.

  1. Run the application on the host computer or server.
  2. Find the host IP address, for example 192.168.1.50.
  3. Create a room with mode LAN.
  4. Share the generated URL, replacing localhost with the host IP if required.
  5. The second computer opens the URL and joins through WebSocket communication on the local network.
Firewall must allow HTTP/HTTPS and WebSocket traffic to the application port inside the LAN.

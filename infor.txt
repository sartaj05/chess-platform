Run commands
unzip chess-platform-module1.zip
cd chess-platform-module1/chess_platform_repo

cp .env.example .env

docker compose up --build

Create admin user:

docker compose exec web python manage.py createsuperuser

Run tests:

docker compose exec web pytest

Run Django checks:

docker compose exec web python manage.py check
docker compose exec web python manage.py makemigrations --check --dry-run
docker compose exec web ruff check .

Production check:

docker compose exec web python manage.py check --deploy
Social login note

Google and GitHub login are wired through django-allauth. Credentials are not hardcoded. Add provider credentials from Django Admin under Social Applications after deployment.

Run commands
unzip chess-platform-module2.zip
cd chess-platform-module2/chess_platform_repo

cp .env.example .env

docker compose up --build

Apply migrations:

docker compose exec web python manage.py migrate

Create admin user:

docker compose exec web python manage.py createsuperuser

Run tests:

docker compose exec web pytest apps/rooms

Run full checks:

docker compose exec web python manage.py check
docker compose exec web python manage.py makemigrations --check --dry-run
docker compose exec web ruff check .
LAN testing

On host machine:

docker compose up --build

Then open:

http://localhost:8000/rooms/create/?mode=lan

Create a LAN room and share the generated URL. On another computer in the same LAN, replace localhost with the host IP:

http://192.168.1.50/play/ABCD1234/

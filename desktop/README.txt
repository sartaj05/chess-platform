CHESS PLATFORM DESKTOP FOR WINDOWS

Installation
1. Extract every file from the ZIP into one folder.
2. Run chess_platform_mobile.exe.
3. Keep the EXE, DLL files and data folder together.

Offline features
- Play against the built-in computer with selectable level and personality.
- Play two-player chess on the same computer.
- Choose board themes and sounds.
- Save games locally in the Windows application-data folder.
- Use tutorials and other bundled chess interfaces without a network connection.

Online features
Login, multiplayer rooms, matchmaking, social features, cloud history, server Stockfish analysis,
notifications, tournaments and leaderboards require a reachable Chess Platform server.

The app never requires the Django server for local bot or same-device games. If Windows displays a
SmartScreen notice for an unsigned internal build, use a code-signed production installer before
public distribution rather than instructing users to bypass the warning.

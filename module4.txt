Run commands
unzip chess-platform-module4.zip
cd chess-platform-module4/chess_platform_repo

cp .env.example .env

docker compose up --build

Apply migrations:

docker compose exec web python manage.py migrate

Check Stockfish:

curl http://localhost:8000/stockfish/status/

Run tests:

docker compose exec web pytest apps/analysis apps/stockfish

Run full checks:

docker compose exec web python manage.py check
docker compose exec web python manage.py makemigrations --check --dry-run
docker compose exec web ruff check .
Manual test flow
1. Open a completed or active game.
2. Click Game Review.
3. Choose depth.
4. Queue Stockfish Review.
5. Open the analysis job page.
6. Wait for Celery to process the game.
7. Review move classifications and evaluation graph.

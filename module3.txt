Run commands
unzip chess-platform-module3.zip
cd chess-platform-module3/chess_platform_repo

cp .env.example .env

docker compose up --build

Apply migrations:

docker compose exec web python manage.py migrate

Run tests:

docker compose exec web pytest apps/games

Run full checks:

docker compose exec web python manage.py check
docker compose exec web python manage.py makemigrations --check --dry-run
docker compose exec web ruff check .
Manual test flow
1. Open /rooms/create/
2. Create a room.
3. Open invite URL in another browser/private window.
4. Both players click Ready.
5. Click Start Game.
6. Move e2 to e4.
7. Confirm realtime board update.
8. Download PGN.
9. Export FEN.
